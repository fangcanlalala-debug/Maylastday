第一部分：创建网站

使用 Trae 创建你的第一个网站！

步骤：

  1. 打开 Trae 平台
  2. 让 AI 帮你创建一个网站（比如个人艺术博客）
  3. 在 Trae 云环境里预览网站效果
  4. 下载网站文件到本地电脑
💡 提示：Trae 会自动生成完整的网站文件，包括 HTML、CSS、JavaScript 等。

第二部分：准备 Git 和 GitHub

2.1 安装 Git

  • Windows: 下载 https://git-scm.com/download/win
  • macOS: 系统自带，无需安装
  • Linux: sudo apt install git

2.2 配置 Git

git config --global user.name "你的GitHub用户名"
git config --global user.email "你的邮箱"

2.3 创建 GitHub 仓库

  1. 打开 https://github.com/new
  2. 填写仓库名（比如 my-art-blog）
  3. 选择 Public 或 Private
  4. 不要勾选任何初始化选项
  5. 点击 Create repository

2.4 创建个人访问令牌（Token）

  1. 打开 https://github.com/settings/tokens
  2. 点击 Tokens (classic)
  3. 点击 Generate new token → Generate new token (classic)
  4. Note 填：my-token
  5. Expiration 选：No expiration
  6. Scopes 勾选：repo
  7. 点击 Generate token
  8. ⚠️ 复制生成的 token（ghp_ 开头），保存好！只显示一次！

第三部分：首次上传到 GitHub

3.1 进入项目文件夹

在终端里，进入你解压后的网站文件夹：

cd /path/to/my-art-blog

3.2 初始化 Git

git init
git add .
git commit -m "feat: initial release"

3.3 关联远程仓库

git remote add origin https://github.com/你的用户名/仓库名.git
git branch -M main

3.4 把 Token 加到 URL（重要！）

git remote set-url origin https://你的token@github.com/你的用户名/仓库名.git

3.5 推送到 GitHub！

git push -u origin main

第四部分：启用 GitHub Pages

  1. 打开你的 GitHub 仓库
  2. 点击 Settings（设置）
  3. 左侧菜单找到 Pages
  4. Source 下拉选择 Deploy from a branch
  5. Branch 选择 main 和 / (root)
  6. 点击 Save
⏰ 等待 1-5 分钟，网站就上线了！

你的网站地址：

https://你的用户名.github.io/仓库名/

第五部分：以后如何更新网站

只需三步：

git add .
git commit -m "描述你的修改"
git push

完整示例：

# 1. 在本地电脑修改文件
# 2. 提交并推送
git add .
git commit -m "feat: 更新首页文案"
git push

# 3. 等几分钟，GitHub Pages 自动更新！

第六部分：常见问题

Q: 推送时提示输入密码，怎么办？

A: GitHub 不再支持密码登录，需要用个人访问令牌（Token）。把 Token 加到 URL 里就不用每次输密码了。

Q: Token 忘记了怎么办？

A: Token 只显示一次，忘记就去 https://github.com/settings/tokens 重新生成一个。

Q: 网站更新后要等多久才能看到？

A: 通常 1-5 分钟，刷新一下浏览器就能看到了。

Q: 本地文件和 GitHub 上不一样怎么办？

A: 确保你在正确的文件夹里，用 git status 查看当前状态。
